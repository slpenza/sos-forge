# Where the data comes from, and what you may do with it

Every dataset sos-forge builds is made from someone else's data, so each one carries that source's credits and
licence. This page lists every source the bundled recipes use, what its terms allow, and the credit each dataset carries.
It was last checked on 22 November 2026.

## What a dataset needs to carry

- **Credits.** sos-forge writes them into the playlist description and the README that travel with every
  dataset. Keep them when you copy the folder to a sphere.
- **A share-alike licence when the data requires it.** Pinball Map (CC BY-SA 4.0) does. The dataset's README
  says so.
- **OpenStreetMap's credit.** "© OpenStreetMap contributors" must stay with any image made from it.
