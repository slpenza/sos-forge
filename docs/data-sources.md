# Where the data comes from, and what you may do with it

Every dataset sos-forge builds is made from someone else's data, so each one carries that source's credits and
licence. This page lists every source the bundled recipes use, what its terms allow, and the credit each dataset carries.
It was last checked on 22 November 2026.

## Sources the bundled recipes use

| Source | Used for | Terms in short | Status | Credit the dataset carries |
|---|---|---|---|---|
| NASA Scientific Visualization Studio, CGI Moon Kit | Lunar Phases | NASA imagery isn't copyrighted; credit NASA | Free to use | NASA's Scientific Visualization Studio CGI Moon Kit: LRO LROC colour and LOLA elevation |
| NASA GIBS: Black Marble, Blue Marble | The night and day Earth backgrounds | NASA imagery isn't copyrighted; credit NASA | Free to use | NASA Black Marble or Blue Marble, via NASA Global Imagery Browse Services |
| OpenStreetMap, through the Overpass API | Where the World Plays | ODbL. A rendered image is a "Produced Work" and must credit the contributors. The public Overpass server is for light use | Free to use. Queries are cached for 30 days and paced | © OpenStreetMap contributors |
| Pinball Map | Pinball Map | CC BY-SA 4.0. Every API call needs a token, approved by hand. A dataset made from it must credit Pinball Map and be shared under the same licence | Needs a token. Request one at pinballmap.com/api_token | Pinball Map (pinballmap.com), CC BY-SA 4.0 |
| Your own GPS files | My Activities | Yours | Free to use. The first and last 400 m of each track are trimmed so your home doesn't show | Whatever you choose |

## What a dataset needs to carry

- **Credits.** sos-forge writes them into the playlist description and the README that travel with every
  dataset. Keep them when you copy the folder to a sphere.
- **A share-alike licence when the data requires it.** Pinball Map (CC BY-SA 4.0) does. The dataset's README
  says so.
- **OpenStreetMap's credit.** "© OpenStreetMap contributors" must stay with any image made from it.
