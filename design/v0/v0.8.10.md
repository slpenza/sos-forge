# v0.8.10 — Help moves to Ask & Answer v0.24.0, which keeps its own text at 14px and hides its own heading

sos-forge asked Ask & Answer for two settings, so it could stop restyling Ask & Answer's classes by name (v0.7.4,
v0.5.3). Ask & Answer v0.23.0 added a minimum text size and v0.24.0 a hidden heading. This version pins v0.24.0 and
uses both.

## What it decides

**The pin moves from v0.19.15 to v0.24.0.**
- **How:** `ask.lock.json` was written by v0.24.0's own `corpus.py --lock`. That file's sha384 was checked first
  against the one `GET /ask` lists.
- **Seven files pinned,** as before.
- **The releases in between** add the token records, the usage reports and image conversion on Sonnet 5.5. None
  changes what sos-forge's pages do.

**Help's text floor is Ask & Answer's own.**
- **What changed:** every size under 1em in v0.24.0's panel, all 37 of them, is written as
  `max(var(--ask-min-size), <its fraction>)`. Ask & Answer's default floor is 11px.
- **sos-forge's setting:** `--ask-min-size: 14px`, in `site/help-head.html` for Help and in `site.css` for the home
  page's Ask box.
- **What goes:** the 22 rules in `help-head.html` that raised Ask & Answer's classes to 14px by name, and `site.css`'s
  rule for the home Ask button. A renamed class can no longer slip past them.

**The heading is hidden by Ask & Answer.**
- **The setting:** `[help] ask` in `site/site.toml` sets `showHeading = false`.
- **The result:** the panel's heading stays in the page for screen readers and is hidden on screen. The bar already
  says Help.
- **What goes:** `help-head.html`'s own visually-hidden rule for `.ask-hd`.

## What it does not decide

- **The docs' own floors.** The topic list's group names, file names and summaries, and code in the docs are sized by
  `help-head.html` as before. They're the docs viewer's, not the panel's.

## Tested

- **`tests/test_browser.py::test_pinned_panel_honours_the_minimum`** replaces `test_help_floor_covers_the_pinned_panel`:
  - the pinned stylesheet uses `--ask-min-size` and has no fixed size under 14px at 17px;
  - `help-head.html` and `site.css` both set it to 14px.
- **`test_home_ask_box_hands_the_question_to_help`,** on v0.24.0:
  - the home box hands its question to Help;
  - Help has no text under 14px, before the answer and in the error state the refusal leaves;
  - the heading is on the page but not on screen;
  - `site.toml` sets `showHeading = false`, and the test's frame does too.
- **`test_pages_load_clean` and `test_no_text_is_smaller_than_14px`** pass on every page.
- **The suite:** 201 Python tests (with the browser tests required) and 27 node tests pass. `infra/` is unchanged,
  and its 26 tests pass in v0.8.9.
