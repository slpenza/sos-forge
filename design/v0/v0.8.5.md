# v0.8.5 — sos admin moves to port 8041, inside sos-forge's block

stevenpenza.com's port plan (its v0.7.25) gives each project a block of ten local ports, and sos-forge's is 8040 to
8049. `sos site --serve` already used 8040. `sos admin` used 8030, outside the block, and 8030 to 8039 has been held
free until it moved.

## What it decides

- **`sos admin` serves on 127.0.0.1:8041 by default.** `admin.ADMIN_PORT` is the one default: `admin.serve` takes it
  and `sos admin --port` names it in its help. `--port` still picks another.
- **Nothing else changes.** The page, its token and its checks are as before. A bookmark to port 8030 needs updating.

## What it does not decide

- **The other eight ports** in the block, 8042 to 8049. They stay free for sos-forge's next local servers.

## Tested

- **`tests/test_cli.py::test_local_servers_use_sos_forges_ports`:**
  - `sos site --serve` defaults to 8040 and `sos admin` to 8041, both inside 8040 to 8049;
  - `admin.serve`'s default matches the command line's.
- **By hand:** port 8041 was free on this computer, and the admin page, served on its default port with stand-in
  ports, answered 200.
- **The suite:** 196 Python tests (with the browser tests required), 27 node tests and 26 infra tests pass.
