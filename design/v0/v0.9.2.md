# v0.9.2 — The home page drops "Open the simulator" and draws Ask as the site's buttons; "Record catalog link" waits for a submission

Three buttons were off.
- **"Open the simulator":** the home page's hero repeated the top bar's Simulator link.
- **Ask:** Ask & Answer's button sat beside the site's buttons in a style of its own.
- **"Record catalog link":** `sos admin` showed it on every dataset, including ones never sent to NOAA. A catalog
  link only ever follows a submission.

## What it decides

**The home page:**
- **"Open the simulator" goes.** The top bar's Simulator link already opens it, so the hero's row is "Read the
  help" and the question box.
- **Ask & Answer's Ask button is drawn as the site's `.btn`,** like Download and Read the help: rounded corners,
  the panel fill, the site's border and font, and no spaced monospace. It keeps the question field's 46 px height,
  so the two line up.
  - **How:** one rule in `site/css/site.css` on `.cta .ask-box .ask-boxbtn`. Ask & Answer has no settings for its
    button, so this restyles its class by name, which v0.8.10 had moved away from. The browser test compares the
    button with Read the help in Chrome, so a pin that renames the class fails.

**sos admin:**
- **When the button shows:** once a dataset has a thread, meaning its stored copy or a reply has been filed, or when
  it already has a link. The latter keeps "Change catalog link".
- **Why a thread, not a reply from NOAA:** a reply that doesn't thread under the submission lands in Unfiled. If the
  button waited for a filed reply, a dataset NOAA accepted that way could never get its link.
- **The server is unchanged:** `/api/catalog` still records a link for any dataset in `site.toml`. Only the page
  waits.

## What it does not decide

- **The question field's corners.** They stay square, as Ask & Answer draws them.
- **What's new.** These are layout changes, so the version has no For visitors lines.
- **Anything else on sos admin:** the statuses, drafts and sends are as they were.

## Tested

- **`test_browser.py::test_home_ask_box_hands_the_question_to_help`:** the hero's only `.btn` is Read the help,
  and the Ask button's computed radius, fill, border colour, text colour, font, size, weight, letter spacing and
  padding equal Read the help's, against the pinned Ask & Answer panel.
- **`test_browser.py::test_admin_offers_catalog_link_once_sent`,** in Chrome over the real server with fake ports:
  - an unsent dataset has no catalog button;
  - one with a recorded link shows "Change catalog link";
  - once a stored copy arrives, the unsent dataset shows "Write to NOAA" and "Record catalog link".
- **`test_browser.py::test_admin_sends_a_test`:** unchanged, and still passing.
