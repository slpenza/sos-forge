# v0.4.9 — Help moves to Ask & Answer v0.19.14: one combined answer, at the page's width

"Can I add my own dataset?" is answered by four of the help pages. Ask & Answer showed four answers, each with its
own references, and the desk layout held them to 740 px on any screen.

## What it decides

**`ask.lock.json` pins Ask & Answer v0.19.14,** up from v0.19.4.
- **How:** `corpus.py --lock`, run from v0.19.14's own `corpus.py`, checked against the integrity `GET /ask` lists.
- **What it brings:**
  - **A combined answer:** when two or more pages answer, the panel shows one short answer, "Combined from N
    pages". Each sentence links to the lines it rests on. "Show each page's answer" opens the separate answers.
  - **The fallback:** if combining fails or times out, readers get the separate answers, with no error.
  - **The width:** the desk panel takes the page's width. The text stays at 68 characters, with references beside
    it when there's room and under it when there isn't.
- **Its cost:** the combining call adds about 1.3 s and about $0.0015 to a question that combines, measured by Ask &
  Answer on these docs.
- **The releases in between,** v0.19.5 to v0.19.13, are Ask & Answer's own fixes:
  - project keys have one rule, which `sos` already meets;
  - a project's served root is computed once, and these docs share one folder;
  - the rest is upload, image and retry handling on its side.
- **Nothing in sos-forge's code changes for it.** The panel asks to combine by default, and the help frame in
  `site/site.toml` keeps its keys.

**`ask_base` is `https://ask.stevenpenza.com`,** Ask & Answer's own address, instead of its execute-api one.
- **Why:** it is the one address the `ask` standard names, and the one the release script turns into the CSP's
  allowance.
- **Same API:** it names the same release, serves its artifacts under its own domain, and allows
  sos.stevenpenza.com.

## For visitors

- Help: when several pages answer a question, Help gives one short combined answer, each sentence linked to the
  lines it rests on, and answers use the page's width.

## What it does not decide

- **The help pages' structure.** The four pages keep their own topics; the combined answer joins them per question.
- **Turning combining off.** It is Ask & Answer's default, and its fallback shows today's view.
