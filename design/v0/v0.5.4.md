# v0.5.4 — Help's question box is the home page's width

On a wide screen Help's question box ran the whole width of the page, about 1,390 px at 1440, while the home page's
was about 494 px in its introduction. Steve asked for Help's to match the home page's, lined up with the text under
it.

## What it decides

**Both question boxes are capped at the same 480 px.**
- **Help:** `site/help-head.html` caps the panel's question row (`.ask-askform`) at 480 px. It sits at the left of
  the page, over the topic list.
- **The home page:** `.cta .home-ask` had no width of its own. It filled what the introduction's row left after the
  two buttons, which varied with the window. It now asks for 480 px (`flex: 1 1 480px`) and is capped there:
  - it shares the buttons' row when 480 px fits beside them;
  - it wraps to a row of its own when it doesn't, rather than shrinking. At 768 px it had shrunk to 408 px.
- **On a phone:** both still fill the row, between the same 12 px gutters (v0.5.3).
- **Turned down:** making the home page's box wider instead. Steve chose Help's to match.

## For visitors

- Help: the question box is the same width as the home page's on a wide screen, lined up with the topics under it.

## What it does not decide

- **The answers.** An answer, its references and "Show each page's answer" still use the page's width (v0.4.9).

## Tested

- **Both boxes measured on a local build, field to button:**

  | Width | Home | Help |
  |---|---|---|
  | 390 px | 366 px | 366 px |
  | 600 px | 480 px | 480 px |
  | 768 px | 480 px | 480 px |
  | 1024 px | 480 px | 480 px |
  | 1440 px | 480 px | 480 px |

  No sideways scroll at any width.
- **`test_home_ask_box_hands_the_question_to_help`** now checks both are 480 px at the tests' 1280 px window,
  against the real pinned Ask & Answer release.
- **The suite:** 169 Python tests and 18 node tests pass, with the browser tests required.
