# v0.3.1 — Play a dataset's flat preview from the gallery, show its dates, and build cleanly without Ask & Answer

Until now the gallery showed each dataset as a still poster, and the only way to see one move was to open it in the
simulator. This version adds a play button to every movie card that plays the flat (equirectangular) preview in
place of the poster, so a visitor can see the whole map at once without loading a sphere. Each card also shows the
span of time its dataset covers. The broken Ask page goes, and a copy of the site built without Ask & Answer no
longer links to help pages it doesn't have.

## What it decides

**The button plays the preview the site already publishes.**
- Every movie card gets a round play button centred on its poster. The video it plays is `preview.mp4`, which
  the site already encodes for the simulator (H.264, at most 2,048 px wide).
- **Nothing loads until the button is pressed.** The `<video>` element is created on the click, so the gallery
  page stays as light as before.
- **Still images get no button.** Their poster already is the flat image.

**The browser's own controls take over once it plays.**
- The video replaces the poster, muted and looping, with native controls. Those give pause, scrubbing and full
  screen without new code.
- Starting one preview pauses every other, so a long gallery never plays several at once.
- Focus moves to the video, so a keyboard user who pressed the button can pause it straight away.

**The poster stays a link to the simulator.** A button inside a link is invalid HTML, so the poster area is now a
`div` holding the link and the button side by side. Clicking anywhere on the poster except the button still opens
the simulator.

**Styling.** A translucent circle with a white triangle, both drawn in CSS (no SVG and no new files). It turns
amber on hover and shows the site's focus ring. Its size scales with the card: between 44 and 60 px, about 14% of
the poster's width.

**Each card shows its dates in a pill before the length pill.** The date is what the dataset is about, so it comes
first, in a neutral outline. The length stays amber.
- **Where the label comes from:**
  - `sos site` reads `[animation] start` and `end` from the recipe the dataset's slug names.
  - Spans of two years or more read as years: Getting Richer is "1820–2022" and Cities Growing "1975–2030".
  - Shorter spans read as day dates.
- **A `dates` key on a `site.toml` dataset** overrides that or fills it in. Tonight's Aurora has no span, so it says
  "23 Nov 2026, 02:06 UTC", the forecast time its 4K build drew (from that build's grid metadata).
- **Where the World Plays shows no dates.** It steps through sports, not time.
- `datasets.json` entries carry `dates`, which is `null` when there is none.

**The Ask page and its nav entry go.** Steve decided the site has one header entry, Help, with an ask box on the
home page that hands its question to `/help/#ask=<question>` (relayed by ask-answer-c2).
- `ask.html` never worked: `js/ask.js` imported `./ask/ask-panel.js` relative to `/js/`, which returns 404, so
  visitors only ever saw "Loading…". Removing it loses nothing they had.
- `ask.html`, `js/ask.js` and the Ask links in the home page, the simulator and the help bar go.
- The home-page box ships with sos-forge's move to Ask & Answer's layouts release, whose Help page reads
  `#ask=`. A box that lands on a page that ignores it would be worse than none.

**A build without Ask & Answer still makes sense.** The help pages need Ask & Answer's private tools, which a
fork's CI can't reach.
- Without an ask-answer checkout, `sos site` builds the gallery and simulator as before.
- It rewrites every link to `/help/` to `docs/getting-started.md` on GitHub, under `site.toml`'s `repo`. That is
  the home page's Help entry and its "Read the help" button, the simulator's Help entry and the 404 page.
- The warning says how many links it changed. A build with the help pages keeps its links.

## For visitors

- Gallery: a movie's card plays its flat preview in place, without opening the simulator.
- Gallery: each card shows the span of time its dataset covers.

## What it does not decide

- **Dates written into the bundle.** The label comes from the recipe in the repo, so a recipe changed after its
  data release was built would disagree with the zip. Writing the span into each bundle needs a rebuild, which the
  planned length variants need anyway.
- **A pitch for Ask & Answer in builds without it.** Steve may want one later.
- **Captions.** The simulator shows `labels.txt` captions over the sphere; the flat preview does not. Text the
  recipe draws into the frames (HUD and legends) does show, distorted as it is on any flat map.
- **Unmuting.** The datasets have no sound.
- **A flat view in the simulator.** That would be a third view beside Orbit and Visitor; this version only
  touches the gallery.

## Tested

- **`pytest`:** 134 tests. The version moves to 0.3.1 in `pyproject.toml` and `sosforge/meta.py`. New and
  changed tests cover:
  - `date_label` for year spans, day spans and a single day
  - `recipe_dates` against the repo's recipes, including one without a span and a missing recipe
  - a `site.toml` `dates` value reaching `datasets.json`, and `null` when a dataset has none
  - a build without an ask-answer checkout:
    - the home page's two Help links, the simulator's one and the 404 page's one point at the docs on GitHub
    - no `help/` links remain, while a build with the help pages keeps them
  - no page and no link to `ask.html` in either build
- **In Chrome against a local `sos site --dist dist` build:**
  - The three movie cards show the button and Tonight's Aurora does not.
  - Clicking Getting Richer's button swapped in a 2,048×1,024 video that was playing 2 s later, with focus on it.
  - Clicking Cities Growing's button then paused Getting Richer at 11.1 s and played Cities Growing.
  - Pressing Enter on Where the World Plays' focused button played it and paused the other two.
  - The poster still links to the simulator.
  - The cards read: Where the World Plays "36 s loop"; Getting Richer "1820–2022", "40 s loop"; Cities Growing
    "1975–2030", "22 s loop"; Tonight's Aurora "23 Nov 2026, 02:06 UTC", "Still image".
  - At 390 px wide (a phone, in an iframe), the button is centred on the poster at 49 px, and the page doesn't
    scroll sideways.
- **Not tested:** Safari and Firefox; real touch devices; the deployed site, which waits for the tag.
